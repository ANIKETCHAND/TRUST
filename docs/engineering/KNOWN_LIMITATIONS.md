## 1. Explicit Product Boundaries & Design Non-Goals

To maintain high engineering credibility with enterprise security architects, AgentTrust explicitly documents the boundaries of its enforcement perimeter. The platform does not claim capabilities outside its actual architectural enforcement boundary.

---

## 2. Subsystem Limitations

### 2.1 Browser Shield (Manifest V3 Extension)
- **Supported Surface:** Operates strictly within supported Chromium-based browsers (Google Chrome, Microsoft Edge, Brave) and targets major enterprise AI web interfaces (`chatgpt.com`, `claude.ai`, `gemini.google.com`, `perplexity.ai`, `deepseek.com`).
- **DOM-Level Limitation:** The extension intercepts input events in the browser Document Object Model (DOM). It does **not** inspect encrypted operating system network sockets, does **not** intercept desktop native AI applications (e.g., Cursor, desktop Claude, LM Studio), and does **not** monitor OS-level clipboard contents until pasted into a targeted browser element.
- **Client Bypassability:** A user with local machine administrative privileges or developer tools access can disable the extension. Enterprise deployments must enforce extension installation via Chrome Enterprise Policy (GPO / InTune).

### 2.2 Prompt Injection Defenses
- **Theoretical Limitation:** Modern computer science research confirms that prompt injection into large language models cannot be 100% eliminated through input filters alone. A sufficiently novel, multi-turn, or steganographically encoded attack may bypass regex and semantic embedding thresholds.
- **Mitigation Strategy:** AgentTrust treats prompt injection filters as **defense-in-depth Layer 1**. The primary line of defense is the **Deterministic Execution Gateway**, **Dynamic Taint Tracking**, and **Strict Server-Side Tool Authorization**. Even if an agent is successfully jailbroken, it cannot execute unauthorized tools, write to unwhitelisted filesystem paths, or exfiltrate data over unapproved network domains.

### 2.3 Endpoint Connector (Windows vs Linux)
- **Current Operating System Support:** Production-tested on Windows 10, Windows 11, and Windows Server (2019/2022) using native `netsh advfirewall` rules and Windows `psutil` process management.
- **Linux Roadmap:** Linux containment (`iptables` / `nftables` and `cgroups` process isolation) is designed into the architecture ([`endpoint-connector/LINUX_ROADMAP.md`](file:///e:/OS%20PROJECT/endpoint-connector/LINUX_ROADMAP.md)) but is not yet validated in automated CI test pipelines.

### 2.4 Threat Intelligence & IP Geolocation
- **Approximation Notice:** Geolocation mappings for remote IP addresses are derived from heuristic database lookups and MaxMind GeoLite approximations. IP geolocation indicates approximate geographic routing, not verified attacker identity. RFC-1918 private subnets are categorized strictly as internal intranet traffic.

### 2.5 AI-Assisted Security Analysis
- **Advisory Status:** Summaries, violation explanations, and forensic narratives generated by AI assistants are advisory tools to accelerate SOC triage. AI outputs must never be treated as verified legal evidence and are never permitted to independently authorize sensitive security actions.
